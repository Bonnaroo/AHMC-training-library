# Training Library

This repository stores editable training files, quiz templates, and supporting materials for EHS training development.

## Purpose

This library is used to create simple, mobile-friendly training pages that can be reviewed, updated, and published for employee training.

## Contents

- Training page files
- Quiz files
- Images and supporting visuals
- QR-code-ready landing pages
- Training templates
- Draft and archived versions

## Important Rules

- Do not upload confidential company information unless the repository is private.
- Do not upload employee personal information.
- Do not use this as the official training record system unless approved.
- Final training records should be stored in the approved system, such as Plex, LMS, SharePoint, or another approved location.
- All EHS content must be reviewed for accuracy before use.

## Basic Workflow

1. Add or update training content.
2. Use AI to convert the content into an HTML training page.
3. Review the content for accuracy.
4. Test the training page.
5. Commit the changes with a clear message.
6. Publish or share the approved version.
7. Create a QR code only after the final link is confirmed.

## Example Commit Messages

- Add aerosol can disposal training
- Update crane hard hat training wording
- Add stormwater awareness quiz
- Fix mobile layout on training page
- Archive old version of spill response training
